ollama list# NovaTech — база знаний для FirstDay AI

Это **синтетическая учебная база знаний** для демонстрации корпоративного RAG. Никакие настоящие внутренние документы компании не использованы.

## Структура

- `00_company` — компания, культура, терминология
- `01_hr` — адаптация и HR-процессы
- `02_it_support` — оборудование, учётные записи, доступы
- `03_security` — политика безопасности
- `04_engineering` — разработка и API
- `05_qa` — качество и тестирование
- `06_devops` — окружения и эксплуатация
- `07_product` — продукт OrbitFlow
- `08_learning` — обучение по ролям
- `09_support` — обращения и обратная связь
- `10_admin` — администрирование RAG/HR
- `11_incidents` — учебные runbooks
- `12_process` — рабочие процессы

## Рекомендуемое использование

1. Загружайте `.md` из всех тематических каталогов; файл `README.md` служебный.
2. Парсите YAML-frontmatter как метаданные; **не считайте поля `audience` и `access_level` взаимозаменяемыми**.
3. Сохраняйте `doc_id`, `title`, `category`, `owner`, `audience`, `access_level`, `status`, `last_reviewed` для каждого чанка.
4. При поиске сначала применяйте **серверные** фильтры доступа и `status=Published`, затем семантический и/или полнотекстовый поиск.
5. Не позволяйте LLM выбирать доступ самостоятельно. HR/ADMIN документы нельзя показывать сотруднику без соответствующей роли.
6. Ответы сопровождайте `doc_id`, заголовком, ссылкой/путём, а при отсутствии релевантных данных просите уточнение или честно отказывайте.
7. При переиндексации документа удаляйте/заменяйте старые чанки, не дублируйте их.
8. В `rag_evaluation.csv` — контрольные вопросы, требуемые ID и пример ожидаемого ответа. Это не готовая оценка качества: измерение Recall@k/groundedness нужно реализовать самостоятельно.

## Демонстрационные границы

Цены, сроки SLA, роли и процедура одобрений — **вымышленная политика NovaTech**. В базе нет действующих паролей, токенов, адресов внутренних сервисов или персональных данных реальных людей. Описание процедур не является советом по праву, медицине или трудовому договору.
