# Учебный трек Junior Java Developer

> **NovaTech / FirstDay AI — учебная демонстрационная документация.** Компания, системы, процедуры и сроки вымышлены и не являются правилами реального работодателя.

## Назначение и контекст

Java-трек на 30 дней: первая неделя — JDK/Git/IDE и запуск сервиса; вторая — REST/DTO/валидация; третья — JPA и тестирование; четвёртая — самостоятельный PR и итоговая демонстрация.

## Для кого эта инструкция

**Аудитория:** ENGINEERING. **Владелец:** Engineering Enablement. **Уровень доступа:** EMPLOYEE. **Статус:** Published.

## Порядок действий

1. Дни 1–5: установка JDK 21, запуск сервиса и знакомство с архитектурой.
2. Дни 6–10: изучение REST API и форматов ошибок.
3. Дни 11–20: реализация небольшого endpoint с тестами.
4. Дни 21–30: PR, review, документация, демо.

## Типичные ошибки и способы решения

- **Ситуация 1.** Если сервис не запускается, сначала проверьте README и версии инструментов.
- **Ситуация 2.** Если задача слишком большая, разбейте её с ментором.

## Вопросы и ответы

**Вопрос:** Что изучать во вторую неделю Java?

**Ответ:** REST, DTO и валидацию.

**Вопрос:** Что показать на 30-й день?

**Ответ:** Проверенный PR и демо.
