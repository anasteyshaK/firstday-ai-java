# Каталог разрешённых программ

> **NovaTech / FirstDay AI — учебная демонстрационная документация.** Компания, системы, процедуры и сроки вымышлены и не являются правилами реального работодателя.

## Назначение и контекст

Разрешённые средства разработки включают IntelliJ IDEA, VS Code, Git, JDK, Docker Desktop при выполнении политики лицензирования и безопасности. Новое ПО требует проверки IT Support.

## Для кого эта инструкция

**Аудитория:** ALL. **Владелец:** IT Support. **Уровень доступа:** EMPLOYEE. **Статус:** Published.

## Порядок действий

1. Проверьте наличие программы в каталоге.
2. Выберите версию, поддерживаемую командой.
3. Для отсутствующего ПО создайте Software Request.
4. После установки обновляйте компоненты по уведомлениям.

## Типичные ошибки и способы решения

- **Ситуация 1.** Не скачивайте исполняемые файлы из непроверенных источников.
- **Ситуация 2.** При ошибке лицензии сообщите IT Support.

## Вопросы и ответы

**Вопрос:** Можно ли ставить любое ПО?

**Ответ:** Нет, нужно проверить каталог.

**Вопрос:** Кому писать про лицензию IDE?

**Ответ:** IT Support.

## Контрольный результат

После выполнения инструкции сотрудник должен уметь объяснить, зачем нужен описанный процесс, показать выполненные действия или заявку в учебной системе Nimbus, а при блокере — указать ответственного владельца. Если шаг невыполним, его следует отметить как заблокированный, а не как завершённый.

## Как поддерживать актуальность

Уточнения и исправления передаются через заявку **Knowledge Feedback** в Nimbus, обязательно с названием документа **NT-018**, описанием противоречия и предложением исправления. Сотрудник не должен менять утверждённые политики только на основании ответа AI.
