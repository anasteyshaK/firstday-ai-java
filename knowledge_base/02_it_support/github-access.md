# Доступ к GitHub и репозиториям

> **NovaTech / FirstDay AI — учебная демонстрационная документация.** Компания, системы, процедуры и сроки вымышлены и не являются правилами реального работодателя.

## Назначение и контекст

Новые сотрудники получают доступ к корпоративной GitHub-организации через SSO и заявку GitHub Access. Конкретные репозитории назначаются по команде; права admin не являются стандартными.

## Для кого эта инструкция

**Аудитория:** ENGINEERING,QA,DEVOPS. **Владелец:** IT Support. **Уровень доступа:** EMPLOYEE. **Статус:** Published.

## Порядок действий

1. Создайте GitHub Access Request с названием команды.
2. Получите подтверждение от владельца репозитория.
3. Привяжите корпоративную учётную запись SSO.
4. Проверьте клонирование только нужного репозитория.

## Типичные ошибки и способы решения

- **Ситуация 1.** 403 Forbidden обычно означает отсутствующее разрешение или SSO.
- **Ситуация 2.** Не создавайте личные PAT без согласования политики.

## Вопросы и ответы

**Вопрос:** Как получить GitHub?

**Ответ:** Создать заявку GitHub Access и пройти одобрение владельца.

**Вопрос:** Получает ли новичок права admin?

**Ответ:** Нет.

## Контрольный результат

После выполнения инструкции сотрудник должен уметь объяснить, зачем нужен описанный процесс, показать выполненные действия или заявку в учебной системе Nimbus, а при блокере — указать ответственного владельца. Если шаг невыполним, его следует отметить как заблокированный, а не как завершённый.
