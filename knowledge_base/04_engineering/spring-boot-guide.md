# Первый запуск Spring Boot сервиса

> **NovaTech / FirstDay AI — учебная демонстрационная документация.** Компания, системы, процедуры и сроки вымышлены и не являются правилами реального работодателя.

## Назначение и контекст

Первую задачу нужно выполнять на учебном или staging окружении. Типичная проверка: сборка, unit tests, запуск приложения и вызов health endpoint. Параметры отличаются по сервисам.

## Для кого эта инструкция

**Аудитория:** ENGINEERING. **Владелец:** Backend Platform. **Уровень доступа:** EMPLOYEE. **Статус:** Published.

## Порядок действий

1. Откройте README репозитория.
2. Проверьте Java -version и наличие Docker.
3. Запустите локальные зависимости.
4. Выполните ./mvnw test или эквивалент проекта.
5. Поднимите приложение и проверьте /actuator/health.
6. Согласуйте учебный PR с ментором.

## Типичные ошибки и способы решения

- **Ситуация 1.** Port already in use — проверьте процессы на порту.
- **Ситуация 2.** Connection refused к БД — проверьте host и readiness контейнера.

## Вопросы и ответы

**Вопрос:** Какой endpoint обычно проверяют?

**Ответ:** /actuator/health, если включён для сервиса.

**Вопрос:** Нужно ли брать production-секреты?

**Ответ:** Нет.
