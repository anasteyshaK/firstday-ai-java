# Локальная среда backend-разработчика

> **NovaTech / FirstDay AI — учебная демонстрационная документация.** Компания, системы, процедуры и сроки вымышлены и не являются правилами реального работодателя.

## Назначение и контекст

Для демонстрационного OrbitFlow backend используется Java 21, Spring Boot, PostgreSQL и Docker Compose. Конкретные версии проверяют в README соответствующего репозитория. Настоящие секреты получают через approved secret manager.

## Для кого эта инструкция

**Аудитория:** ENGINEERING. **Владелец:** Backend Platform. **Уровень доступа:** EMPLOYEE. **Статус:** Published.

## Порядок действий

1. Установите JDK 21 и IDE из каталога ПО.
2. Настройте Git и доступ к репозиторию.
3. Прочитайте README сервиса.
4. Запустите зависимые контейнеры через Docker Compose.
5. Запустите тесты и health endpoint.

## Типичные ошибки и способы решения

- **Ситуация 1.** Если порт занят, проверьте запущенные сервисы и их конфигурацию.
- **Ситуация 2.** Если ошибка подключения к БД, проверьте контейнеры и переменные окружения.

## Вопросы и ответы

**Вопрос:** Какой JDK используется в учебном backend?

**Ответ:** Java 21.

**Вопрос:** Где брать актуальные команды запуска?
