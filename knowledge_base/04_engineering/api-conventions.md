# Соглашения REST API

> **NovaTech / FirstDay AI — учебная демонстрационная документация.** Компания, системы, процедуры и сроки вымышлены и не являются правилами реального работодателя.

## Назначение и контекст

Новые HTTP API используют версионированные пути /api/v1, JSON, предсказуемые коды ответа и единый формат ошибок. Для создания ресурса обычно возвращается 201, для удаления без тела 204.

## Для кого эта инструкция

**Аудитория:** ENGINEERING,QA. **Владелец:** API Platform. **Уровень доступа:** EMPLOYEE. **Статус:** Published.

## Порядок действий

1. Описывайте API contract до реализации.
2. Проверяйте входные данные.
3. Возвращайте понятные 4xx для ошибок клиента.
4. Добавляйте интеграционные тесты и OpenAPI.
5. Не включайте чувствительные поля в ответы.

## Типичные ошибки и способы решения

- **Ситуация 1.** 500 не должен скрывать предсказуемую ошибку валидации.
- **Ситуация 2.** Не возвращайте stack trace клиенту.

## Вопросы и ответы

**Вопрос:** Какой код для успешного создания?

**Ответ:** 201 Created.

**Вопрос:** Какой код для удаления без тела?

**Ответ:** 204 No Content.
