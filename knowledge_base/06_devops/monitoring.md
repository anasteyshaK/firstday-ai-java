# Мониторинг Beacon

> **NovaTech / FirstDay AI — учебная демонстрационная документация.** Компания, системы, процедуры и сроки вымышлены и не являются правилами реального работодателя.

## Назначение и контекст

Beacon собирает метрики сервисов, структурированные логи и трассировки. Для новичков доступ read-only; метрики оценивают вместе с контекстом deploy и user impact.

## Для кого эта инструкция

**Аудитория:** ENGINEERING,DEVOPS,QA. **Владелец:** SRE. **Уровень доступа:** EMPLOYEE. **Статус:** Published.

## Порядок действий

1. Найдите dashboard сервиса в Atlas.
2. Проверьте error rate, latency и saturation.
3. Сопоставьте всплеск с релизами.
4. При проблеме откройте runbook и создайте инцидент.

## Типичные ошибки и способы решения

- **Ситуация 1.** Не интерпретируйте единичный график без контекста.
- **Ситуация 2.** Если данные пусты, проверьте выбранный environment и временной диапазон.

## Вопросы и ответы

**Вопрос:** Какие метрики важны?

**Ответ:** Error rate, latency и saturation.

**Вопрос:** Где найти dashboard?

**Ответ:** Через Atlas.
