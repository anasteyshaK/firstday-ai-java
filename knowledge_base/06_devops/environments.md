# Различия dev, staging и production

> **NovaTech / FirstDay AI — учебная демонстрационная документация.** Компания, системы, процедуры и сроки вымышлены и не являются правилами реального работодателя.

## Назначение и контекст

Dev — среда разработки, staging — предпродакшн проверка, production — рабочая среда для пользователей. Данные, доступы, ресурсы и процедуры выпуска разделены.

## Для кого эта инструкция

**Аудитория:** ENGINEERING,QA,DEVOPS. **Владелец:** SRE. **Уровень доступа:** EMPLOYEE. **Статус:** Published.

## Порядок действий

1. Выясните среду перед запуском команды.
2. Используйте отдельные credentials для окружений.
3. Проводите интеграционные проверки в staging.
4. Для production изменений следуйте change management.

## Типичные ошибки и способы решения

- **Ситуация 1.** Если endpoint неизвестен, смотрите каталог Atlas.
- **Ситуация 2.** Не направляйте тестовую нагрузку на production.

## Вопросы и ответы

**Вопрос:** Для чего staging?

**Ответ:** Для проверки изменений до production.

**Вопрос:** Можно ли использовать production credentials в dev?

**Ответ:** Нет.
