# Docker и Compose для новичка

> **NovaTech / FirstDay AI — учебная демонстрационная документация.** Компания, системы, процедуры и сроки вымышлены и не являются правилами реального работодателя.

## Назначение и контекст

Docker запускает приложение в контейнере, Compose описывает несколько зависимых сервисов. Том PostgreSQL сохраняет данные при остановке контейнера; down -v может удалить тома.

## Для кого эта инструкция

**Аудитория:** ENGINEERING,QA,DEVOPS. **Владелец:** Developer Enablement. **Уровень доступа:** EMPLOYEE. **Статус:** Published.

## Порядок действий

1. Установите Docker Desktop через IT.
2. Проверьте docker version.
3. Запускайте только нужный compose проект.
4. Проверьте docker ps и healthchecks.
5. Останавливайте сервисы без удаления volumes.

## Типичные ошибки и способы решения

- **Ситуация 1.** При конфликте портов проверьте другие compose проекты.
- **Ситуация 2.** Никогда не применяйте down -v к базе с нужными данными.

## Вопросы и ответы

**Вопрос:** Удаляет ли docker compose stop базу?

**Ответ:** Нет.

**Вопрос:** Что может удалить volumes?

**Ответ:** docker compose down -v.
